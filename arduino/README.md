# Arduino Projects

Arduino sketches and supporting tools used in project demonstrations.

## Projects

- `7_stepper_motor_encoder/` - Arduino Mega stepper motor controller with encoder feedback, DM542-style step/dir driver control, serial telemetry, and a Python Tkinter GUI.
- `8_water_level_sensor/` - Arduino analog water level sensor monitor that streams raw readings to a Python Tkinter GUI with percentage calibration.
