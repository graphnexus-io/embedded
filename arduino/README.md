# Arduino projects

- [7_stepper_motor_encoder](7_stepper_motor_encoder/) — stepper motion control
  with quadrature encoder feedback and a Tkinter GUI.
- [8_water_level_sensor](8_water_level_sensor/) — analog water-level telemetry
  and desktop visualization.
- [9_temperature_sensor_module](9_temperature_sensor_module/) — thermistor
  telemetry, threshold-based fan control, and temperature calibration.
- [10_near_infrared_detector_module](10_near_infrared_detector_module/) —
  near-infrared intensity and comparator-state monitoring.
- [11_arduino_tft_spi_display](11_arduino_tft_spi_display/) — serial/TFT MiniOS
  monitor with SD-card filesystem commands and a small editor.
- [12_arduino_retro_games](12_arduino_retro_games/) — Snake, Tetris, Breakout,
  Retro Racing, 2048, Sokoban, and Lunar Lander.
- [13_arduino_sokoban](13_arduino_sokoban/) — 100-level Sokoban game with
  joystick control and EEPROM progress.
